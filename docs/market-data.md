# 株価・指数の当日更新

マーケット概要、日本株を探す、株価チャート、銘柄詳細、ウォッチリストをサーバーで表示する前に、対象銘柄の更新日をSupabaseで確認します。日本時間の当日にまだ取得していなければYahoo Financeのチャートデータを1回取得し、`stock_charts.data` / `fetched_at` と `daily_prices` の最新行を更新します。過去の取引・銘柄マスタは削除しません。銘柄一覧は表示中の24銘柄、ウォッチリストは登録銘柄だけを対象にします。

マーケット概要の指数は `useful_data` の当日更新を確認します。日経225はYahoo Financeのチャート、TOPIXはYahoo!ファイナンスの公開ページ、JPX日経400は日経の公式日次CSVを参照します。取得に失敗した指数は古い値を新しい値として表示しません。指数の更新が部分的な場合は画面に注意を出します。

休場日や市場の寄り前には、直近の取引日の価格が最新です。その日すでに取得を試みたかを `fetched_at` / `updated_at` で判定するため、取引日が昨日でも同じ日に繰り返し取得しません。画面にはチャートの最終取引日、または株価の更新日を表示します。次の日本時間の日付には再取得します。配信元が利用できない場合は保存済みデータと注意を表示し、次回の画面表示で再試行します。

現在の接続元は公開エンドポイントであり、安定性や利用条件が変更される可能性があります。商用配信や確実な更新保証が必要になった場合は、契約済みの株価APIに `src/lib/market/provider.ts` と `src/lib/market/indices.ts` の取得部分を切り替えてください。複数のAmplifyインスタンスで同時に初回アクセスが発生した場合は、同じ銘柄を重複取得する可能性があります。
