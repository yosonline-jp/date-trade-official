# チャートワークスペース

`/chart?code=285A` などのチャートページで、既存の銘柄選択・配色・ページ構成を保ちながら、時間足、表示形式、指標、描画ツールを操作できます。設定は現在開いている画面内で保持します。銘柄を変更すると新しい画面の初期設定になります。

## データと時間足

- **日足**：初期表示です。ページで取得済みの保存日足から計算し、テクニカル指標 API への追加通信は行いません。取引中に保存された日足は途中値を含む場合があります。
- **週足**：同じ保存日足をブラウザー内で集計します。日本時間の月曜を週の開始とし、実在する最初の足を始値・時刻、最後の足を終値として、高値の最大値・安値の最小値を採用します。休日に架空の足を追加しません。進行中の週は途中値です。
- **1分足・5分足・15分足**：選択時に既存の `GET /api/stocks/{code}/technicals?interval=1m&limit=1200` を呼び出します。`interval` は選択に応じて `5m` / `15m` に変わります。取得中は古い時間足のチャートを隠し、失敗時はエラーと「再試行」を表示します。時間足を切り替えた後に古い応答が到着しても、現在の時間足を上書きしません。

分足の配信元は Yahoo Finance です。取得範囲は既存プロバイダーの最大29暦日を目安とし、1分足は7日単位で取得します。配信元の履歴制限によって古い部分が取得できない場合があり、警告と取得本数を画面下部に表示します。日本時間の取引時間内に収まり、取得境界時刻までに終了した足だけを使用します。昼休み・時間外の足や15:30の瞬間的な終値クオートは分足に含めません。

表示はリアルタイム配信ではありません。「確定足」は取得時点で足の終了時刻を過ぎているという意味で、配信元の遅延や後日の訂正がなくなるという意味ではありません。最終データ時刻、取引状態、配信元、警告を確認できます。選択した分足はブラウザー内で最長60秒、かつ次の分境界までキャッシュします。「分足を更新」はこの画面内キャッシュを使わず再取得しますが、既存のサーバー側キャッシュや配信元の遅延は適用されます。自動更新は行いません。

日足の高安・ピボットは前の保存日足、週足は前週、分足は取得範囲内の前取引日の高値・安値・終値を基準にします。分足の取得範囲や終値クオートの扱いによって、分足で求めた値は公式の日足と異なる場合があります。過去へスクロールしても、これらは最新の取得日・週を基準にした目安のままです。

## 表示と指標

「ローソク足」「終値ライン」「平均足」を切り替えられます。平均足は実際の約定価格ではなく、元の OHLC から作った合成値です。指標、上部の OHLC 表示、2点測定、CSV は元の実価格を使います。平均足の描画を選んでも、それらの値は合成価格に置き換えません。

| 指標・補助チャート   | 期間・計算の扱い                                                                                                     |
| -------------------- | -------------------------------------------------------------------------------------------------------------------- |
| MA5 / MA25 / MA75    | 終値の単純移動平均（SMA）。初期状態は MA25 のみ表示                                                                  |
| EMA9 / EMA20 / EMA50 | 終値の指数移動平均。最初の期間分の SMA を初期値にし、以後係数 `2 / (期間 + 1)` で更新                                |
| 任意の SMA / EMA     | 「詳細設定・描画ツール」で種類と2〜200本の整数を指定。既定6本を含め最大12ライン。追加したラインは個別に削除可能      |
| BB                   | 終値20本の SMA と、母標準偏差の±2倍。上限・中心・下限と帯を表示                                                      |
| VWAP                 | 分足のみ利用可能。典型価格 `(高値 + 安値 + 終値) / 3` の出来高加重平均。日本時間の取引日ごとにリセット               |
| 前日高安 / 前週高安  | 最新の取得日・週に対する直前の高値・安値                                                                             |
| ピボット             | 前期間の高値・安値・終値から `P = (H + L + C) / 3`、`R1 = 2P - L`、`S1 = 2P - H`、`R2 = P + H - L`、`S2 = P - H + L` |
| 現在値               | 取得した価格系列の最新終値。ライブの現在値ではありません                                                             |
| 出来高               | 元の出来高を株数で表示。初期状態で表示                                                                               |
| RSI                  | 14本。上昇・下落幅を Wilder 方式で平滑化し、0〜100の別パネルに表示。30・70の補助線付き                               |
| MACD                 | EMA12 − EMA26、シグナル EMA9、ヒストグラム（MACD − シグナル）を別パネルに表示                                        |
| RCI                  | 7本・26本。終値の順位と時間の順位の相関を−100〜100の別パネルに表示                                                   |
| ストキャス           | 直近9本の高値・安値に対する終値の位置を %K、%K の3本 SMA を %D として、0〜100の別パネルに表示                        |
| ADX / DMI            | 14本。ADX・+DI・−DI を同じ補助パネルに表示                                                                           |
| ATR                  | 14本。真の値幅を Wilder 方式で平滑化し、円単位の別パネルに表示                                                       |

期間は選択した時間足の**本数**です。週足の MA25 は25週、5分足の MA25 は25本の5分足です。週足の指標は、日足の指標値を平均するのではなく、集計した週 OHLC から再計算します。RSI・MACD・RCI・ストキャス・ADX/DMI・ATR は初期状態で OFF です。各補助チャートは価格チャートと同じ時間軸で、クロスヘアも連動します。

プリセットは表示形式をローソク足へ戻し、指標の表示をまとめて設定します。表示位置や表示本数は変えません。任意に追加した移動平均はプリセット適用時に取り除きます。

| プリセット   | 表示する指標                                                 |
| ------------ | ------------------------------------------------------------ |
| 標準         | MA25、出来高、最新終値                                       |
| デイトレード | EMA9、EMA20、BB、出来高、RSI、最新終値。分足では VWAP も表示 |
| トレンド     | MA5、MA25、MA75、出来高、MACD、最新終値                      |

価格指標は取得履歴を使って計算した後、表示位置に合わせて切り出します。API の既存指標は取得できた全分足から計算し、最大1,200本を画面へ渡します。既定の MA5 / MA25 / MA75 と EMA9 / EMA20 / EMA50 は、この計算済み値をそのまま描画します。任意に追加した移動平均と平均足は画面へ渡された履歴全体から計算します。ズームやスクロールによって同じ足の値が変わることはありません。計算はその足と過去の足だけを使い、未来の足を参照しません。

計算に必要な本数が不足する期間や欠損値は `null` として扱い、線を描画しません。EMA の初期値にも指定期間分の終値が必要で、MACD シグナルには9個の計算済み MACD 値が必要です。出来高が欠損・負数でも、健全な OHLC の価格足は残します。出来高をゼロとして補完せず、出来高依存の指標は必要に応じて欠損扱いとします。週のうち1日でも出来高が不明なら、その週の出来高も不明です。

## 操作

- **表示本数**：「30本」「90本」「180本」「全期間」で取得履歴の表示範囲を選びます。初期状態と「表示をリセット」は最新90本です。履歴が少ない場合は実際の取得本数になります。
- **拡大・縮小・移動**：ボタン、表示位置スライダー、チャートの横ドラッグを使えます。「過去へ」は表示本数の半分ほど戻り、「最新へ」は現在の表示本数を保って最新側へ戻ります。表示本数の下限は20本、上限は取得履歴全体です。
- **クロスヘア**：ポインター位置の足を選択し、日時・実 OHLC・出来高・表示中の指標値を確認できます。縦線は補助チャートにも連動します。
- **キーボード**：チャートにフォーカスし、左右キーで足を選択、Shift＋左右キーで表示範囲を移動、`+` / `-` で拡大・縮小、Home / End で最古・最新へ移動できます。Escape は選択・測定を解除します。
- **2点測定**：「2点測定」を ON にして始点と終点の足をクリックします。選択した2本の実際の終値、差額、始点に対する変化率、足の間隔を表示します。キーボードでは左右キーで選び Enter で確定します。「測定を解除」でやり直せます。
- **水平線**：「詳細設定・描画ツール」で正の価格を入力し、最大5本追加できます。表示価格範囲外の線は描画せず、価格が範囲内に戻ると表示します。各削除ボタンで取り除けます。
- **全画面**：対応するブラウザーではチャートを全画面にし、「全画面を終了」で戻れます。非対応・開始不可の場合は案内を表示します。

時間足の変更・分足の再取得時は、新しい履歴の最新90本へ表示位置を戻し、足の選択と測定を解除します。取得中・エラー時はチャートを隠して前の有効データを保持し、表示形式、指標、任意の移動平均、水平線の設定を次の時間足へ引き継ぎます。日足・週足に切り替えると VWAP は利用できません。

## 保存

「CSVを保存」は現在表示中の足だけを保存します。UTC / JST の日時、実 OHLC、出来高、主要な既存指標、ON にした移動平均を含み、欠損値は空欄です。平均足表示中も実 OHLC を出力します。画面で OFF にした指標でも、CSV の既存指標列には計算済み値を含みます。

「SVGを保存」は価格と現在 ON の補助チャートを含む描画全体を保存します。背景、アクセシビリティ用のタイトル・説明、時間足、表示範囲、ライン名を含みます。操作中のクロスヘア・測定線は除きます。どちらもブラウザーからファイルをダウンロードし、サーバーやデータベースには保存しません。

## 実装と検証

主なファイルは以下です。外部チャートライブラリー、環境変数、データベースの追加・変更はありません。

- `src/app/(client)/chart/page.tsx`：保存日足と銘柄選択を維持してワークスペースを表示
- `src/components/chart-workspace.tsx` / `.module.css`：時間足、分足取得、キャッシュ、配信元表示
- `src/components/trading-chart.tsx` / `.module.css`：既存の色を使う SVG、指標、操作、出力
- `src/lib/analysis/chart-workspace.ts`：保存日足の正規化、週足、移動平均、平均足、表示範囲、測定
- `src/app/(client)/api/stocks/[code]/technicals/route.ts`：既存 API の `limit` を120〜1,500本の整数に拡張。既定240本は維持
- `tests/chart-workspace-math.spec.ts`：計算・週境界・出来高欠損・未来参照防止の検証
- `tests/chart-workspace-ui.spec.ts`：PC / モバイルの表示、操作、保存、通信、キャッシュ、失敗・切替時の検証

既存の Docker 環境で検証できます。UI テストはサーバーの保存日足を使い、分足の応答だけをブラウザーの fetch で置き換えます。テスト用データを本番コードへ追加しません。全ケースで予期しない `console.error`、ページ例外、画面の横はみ出しを確認します。

```powershell
docker compose exec -T app yarn typecheck
docker compose exec -T app yarn lint
docker compose exec -T app yarn build
docker compose -f docker-compose.yml -f compose.test.yml run --rm e2e yarn test:e2e tests/chart-workspace-math.spec.ts tests/chart-workspace-ui.spec.ts tests/home.spec.ts tests/stock-technicals-api.spec.ts
docker compose -f docker-compose.yml -f compose.test.yml run --rm e2e node scripts/check-chart-workspace.mjs
```

実データスクリプトは通常のテスト完了後に実行してください。結果、PC・スマートフォンの画像、実際に保存したCSV/SVGを `test-results/live-chart-workspace/` に残します。

## 株詳細ページの初期チャート

`/stocks/[code]` の株価チャートも共通の `TradingChart` を使用し、初期状態は「トレンド」です。MA5・MA25・MA75、出来高、MACD、最新終値を表示します。出来高は価格・MACDと同じ時間軸の下段へまとめています。表示本数や指標は画面内で変更でき、銘柄を変えて詳細ページを開くと初期設定に戻ります。`/chart` の初期状態は従来の「標準」のままです。

`src/components/stock-detail-chart.tsx` で保存日足と出来高を時刻で対応付け、既存の `savedChartPoints` と指標計算を使用します。価格足と出来高の欠損を区別し、追加の株価API通信は行いません。計算には表示範囲外も含む保存済み履歴を使います。

2026年10月6日の変更確認では、既存のチャート・デイトレード指標の操作テスト24件、型チェック、Lint、本番ビルドが成功しました。Lintは既存の警告55件、エラー0件です。モックを使わず日本株検索から開いた285A（PC・スマートフォン）と7203（PC）で初期表示を確認し、詳細と `/chart` のトレンドから保存したCSVのOHLC・出来高・全指標値が一致しました。指標をOFFにした後も表示本数の変更で設定が戻らず、追加のテクニカルAPI通信・ブラウザーエラー・横方向のはみ出しはありませんでした。

## 定義の参考資料

- [TradingView：平均足の計算方法](https://www.tradingview.com/support/solutions/43000619436-understanding-heikin-ashi-charts/) — 本実装の平均足も、前の平均足の始値・終値から次の始値を求め、元の OHLC の平均を終値とします。最初の始値を元の始値・終値の平均とする初期化は本アプリの仕様です。
- [TradingView：非標準チャートのデータ](https://www.tradingview.com/pine-script-docs/concepts/non-standard-charts-data/) — 平均足の合成 OHLC と実際の市場価格の違い。
- [Zerodha Varsity：Chart types、3.5 Timeframes](https://zerodha.com/varsity/chapter/chart-types/) — 週の始値・高値・安値・終値の集約。日本時間・月曜開始・休日の最初の実在足を使う境界処理は本アプリの仕様です。
- 詳細な指標定義は既存の [デイトレード指標の説明](./stock-technicals.md) も参照できます。
