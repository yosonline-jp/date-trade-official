# DTロゴとブルーテーマ

提供された `public/logo-dt.png` を共通ロゴとして使用します。画像そのものを保持し、色加工・フィルター・影を加えず、代替テキストを付けて表示します。ロゴのネイビー、コバルトブルー、シアンに合わせ、画面のブランド色を共通の `--dt-*` トークンへまとめています。

サイドバー、モバイルヘッダー、フッター、認証画面、About画面で同じロゴを使います。ブラウザーアイコンとApple用アイコンもこのPNGを指定し、モバイルブラウザーのテーマ色を背景のネイビーに合わせています。

## 検証

`scripts/check-brand-theme.mjs` はモックを使わず、PCとスマートフォンで次の画面を確認します。

- マーケット概要、チャート、285A銘柄詳細、デイトレード分析
- ログイン、ウォッチリスト、トレード基礎、日本株一覧、お問い合わせ
- About画面とブラウザーアイコンの指定

ロゴ画像の読み込み・代替テキスト・加工指定の有無、実行時エラー、ページ全体の横方向のはみ出し、背景・文字・アクセントの計算済みスタイルを記録します。未ログインのウォッチリストがログイン画面へ移動した場合は、移動先も記録します。

見出し、本文、選択中のナビゲーション、主要ボタン、フォーム、チャートなどの文字をサンプリングし、sRGBの相対輝度から `(明るい側の輝度 + 0.05) / (暗い側の輝度 + 0.05)` を算出します。主要サンプルは4.5:1以上を検証します。半透明の文字・単色背景は合成して計算し、グラデーション・背景画像・フィルター・要素全体の透過を含む場所は理由を記録して画面画像で確認します。

実行方法は既存のPlaywright環境で次のとおりです。`PLAYWRIGHT_BASE_URL` の省略時は `http://localhost:3002` を使用します。

```sh
node scripts/check-brand-theme.mjs
```

`test-results/brand-theme/report.json` に確認結果を保存し、同じフォルダへPC・スマートフォンの画面上部と主要チャート・指標パネルの画像を保存します。画像は通常のCSS倍率で取得します。テスト実行が出力フォルダを整理するため、このスクリプトは既存UIテストの後に実行します。

## 2026年10月6日の確認結果

PC・スマートフォンの20表示でロゴの読み込みとブラウザーアイコンを確認し、実行時エラーと横方向のはみ出しはありませんでした。文字色の166サンプルはすべて4.5:1以上でした。主要画面の操作テストは49件成功、PCでは対象外のスマートフォン専用テスト1件をスキップしました。型チェック・本番ビルド・Lintも成功し、Lintはエラー0件、既存の警告55件でした。
